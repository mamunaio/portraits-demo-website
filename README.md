# Wild & Wilder Portraits 📸

A premium, modern photography portfolio website designed for a luxury editorial aesthetic. 

Built with **Next.js 16 (App Router)**, styled with **Tailwind CSS**, and animated beautifully using **Framer Motion**. The design leans heavily into 2026 web design trends, featuring a cinematic dark theme, glassmorphism, dynamic 3D interactions, and Bento grid layouts.

## ✨ Features

- **Dark Mode Aesthetic:** A meticulously crafted dark theme (Onyx/Charcoal) with a subtle film grain overlay that feels cinematic and moody.
- **3D Interactive Hero:** Mouse-tracking Ken Burns and 3D tilt effects on the homepage and portfolio pages for a highly immersive first impression.
- **Bento Box Galleries:** Organic, multi-column photo grids with smooth hover gradient overlays and metadata reveals.
- **Glassmorphism UI:** Apple visionOS-inspired frosted glass effects on cards, navigation, and form elements.
- **Floating Navigation:** A sleek, minimal floating pill dock for seamless navigation across dark photography backgrounds.
- **Performance Optimized:** Built on the latest Next.js 16 using Turbopack and React Server Components for lightning-fast loads.

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (React 19)
- **Styling:** Tailwind CSS (Vanilla utilities, custom variables)
- **Animations:** Framer Motion (useSpring, useTransform, useMotionValue)
- **Icons:** Lucide React

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mamunaio/portraits-demo-website.git
   cd portraits-demo-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the result.

## 📂 Project Structure

- `app/` - Next.js App Router pages (Home, About, Portfolio, Sessions, Contact) and global layouts.
- `components/` - Reusable UI components (`Hero`, `GalleryGrid`, `Testimonials`, `FAQAccordion`, etc.).
- `public/` - Static assets and global CSS variables.

## 🎨 Design Philosophy

"We live in 2026, the UI should reflect 2026 design trends." 
This project was built to completely break away from generic, template-looking photography sites. It prioritizes **spatial UI, glassmorphism, dark mode, and cinematic typography** to ensure a high-end client experience from the moment the page loads.
